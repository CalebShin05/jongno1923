# 1923 종로 장날

1920년대 실력 양성 운동(물산 장려 운동, 민립 대학 설립 운동)을 장터 사람 8명의 목소리로 따져 보는 고등학교 한국사 수업 활동입니다.

- 학생 화면: 이 저장소의 GitHub Pages 주소
- 학생 기록: 이 저장소에는 저장되지 않습니다. 「선생님께 제출」을 누르면 선생님 구글 시트로만 전송됩니다.
- 장터 인물은 모두 1920년대 자료를 바탕으로 재구성한 가상 인물입니다.

## 처음 한 번 설정

### 1. 학생 화면 열기 (GitHub Pages)
저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**. 1~2분 뒤 주소가 나옵니다.

### 2. 제출 우체통 만들기 (구글 시트)
1. 학교 구글 계정으로 새 구글 시트를 만듭니다. (이름 예: 종로 장날 제출)
2. **확장 프로그램 → Apps Script**를 엽니다.
3. 원래 있던 코드를 지우고 `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장합니다.
4. **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한 승인을 마칩니다. ("확인되지 않은 앱" 화면이 나오면 고급 → 이동)
6. 나온 **웹 앱 URL**(…/exec로 끝남)을 복사합니다.

### 3. 게임에 우체통 주소 넣기
`index.html`에서 `const SUBMIT_URL = '';` 따옴표 안에 6번 주소를 넣고 저장(커밋)합니다.

## 수업 뒤
구글 시트의 「제출」 탭에 학생 한 명이 한 줄씩 쌓여 있습니다. **파일 → 다운로드 → Microsoft Excel(.xlsx)** 로 엑셀 파일을 받을 수 있습니다. 같은 학생이 여러 번 내면 줄이 여러 개 생기니, 가장 아래(최근) 줄을 보면 됩니다.
